# Локальное SEO BIMM

Задача SEO площадки — дать Google и Яндексу понять, что BIMM это **локальный маркетплейс Приднестровья**, и на запрос
вроде «мышь купить», отправленный из Тирасполя, показывать товары магазинов, которые находятся рядом.

Важно: ни один код не гарантирует позиции в выдаче. Код убирает технические препятствия и отдаёт поисковику
однозначные сигналы «товар продаётся в этом городе, у этого магазина». Остальное (индексация, ссылки на сайт, отзывы,
карточки на картах) зависит от действий вне кода — они перечислены в конце.

## Как поисковик понимает «рядом»

Поисковик определяет близость по трём группам сигналов:

1. **Текст страницы** — «купить» и название города в нужном падеже в `<title>`, описании и заголовке H1.
2. **Разметка schema.org** — у товара указан магазин, его адрес, населённый пункт и страна.
3. **Структура адресов** — у каждого города свой набор страниц (`/tiraspol`, `/tiraspol/catalog/myshi`,
   `/tiraspol/product/…`), а у товара один основной адрес (canonical) — в городе магазина.

## Что реализовано

### Заголовки, описания и H1 (`SeoService`)

Шаблоны собирает `App\Services\SeoService`. Город подставляется в предложном падеже («в Тирасполе», «в Бендерах»);
склонением занимается `App\Support\RussianLocative`, для городов ПМР есть словарь, для остальных — правила окончаний.
Если автоматика ошиблась, в админке («Населённые пункты») можно вписать верную форму в поле «Название в предложном
падеже» (`settlements.name_in`) — оно важнее автоматики.

| Страница | Title (пример) |
|---|---|
| Главная города | Купить в Тирасполе: товары и магазины — BIMM |
| Главная без города | Купить в ПМР: товары и магазины Приднестровья — BIMM |
| Каталог | Каталог товаров в Тирасполе — купить у местных продавцов — BIMM |
| Категория | Мыши — купить в Тирасполе, цены от 350 руб. — BIMM |
| Товар | Мышь Logitech M185 — купить в Тирасполе, цена 350 руб. — BIMM |
| Магазин | Техномир в Тирасполе — товары, цены, контакты — BIMM |
| Список магазинов | Магазины в Тирасполе — каталог местных продавцов — BIMM |
| Скидки | Скидки и акции в Тирасполе — купить со скидкой — BIMM |

- На главной города `meta_title` и `meta_description` населённого пункта (если заполнены в админке) важнее шаблона.
- Description — до 158 символов, обрезается по границе слова, содержит город, число товаров и магазинов, минимальную
  цену. Числа берутся из кеша (`SEO_STATS_TTL`).
- H1 страниц совпадает по смыслу с title и тоже содержит город («Мыши в Тирасполе»); берётся из `$seoHeading`.
- Из шаблона справки удалён блок-заготовка с английским текстом и «Lorem ipsum» и двумя лишними H1.

### Canonical и индексация

- Товар и магазин имеют **один** основной адрес — в городе магазина (`/tiraspol/product/…`), даже если открыты по
  общему `/product/…`. Так поисковик не делит вес между копиями и привязывает товар к городу.
- Пагинация без фильтров получает собственный canonical `?page=N`; адреса с фильтрами и сортировкой — `noindex, follow`.
- `noindex, follow` получают служебные страницы (поиск, заказы, «показать ещё»), а также **пустые** страницы категорий,
  магазинов, каталога города и распродаж — они остаются доступными пользователям, но не попадают в индекс как «тонкие».
- `/home` отдаёт постоянный редирект на `/`.
- `robots.txt` закрывает `/account/`, `/admin/`, заказы, избранное, поиск, `/location` и `…load-more`; указывает
  `Sitemap`.

### Микроразметка schema.org (`StructuredDataService`)

Выводится во всех трёх публичных темах одним общим блоком `partials/seo/head.blade.php`:

- **Organization** и **WebSite** (с поиском по сайту) — только на главной; `areaServed` — город или «Приднестровье»,
  `sameAs` — из `SEO_SAME_AS`.
- **BreadcrumbList** — каталог, категория, товар, магазин, список магазинов, распродажи.
- **Product + Offer** — цена, валюта, наличие, магазин как `Store` с адресом (`PostalAddress`: населённый пункт, улица,
  страна), телефон, `areaServed` (город) и `availableAtOrFrom`. Выдуманных рейтингов и брендов нет.
- **Store** — на странице магазина.

Блок Open Graph и Twitter Card (`og:title`, `og:type`, `og:url`, `og:locale`, `og:site_name`, `og:image`) тоже общий.
Если сборка SEO-данных упадёт, страница всё равно отдаётся: подставляются canonical = адрес запроса и
`index, follow`, ошибка попадает в лог.

### Перелинковка

В подвале всех тем выводится «Купить товары в городах:» — ссылки на главные страницы городов, в которых есть
видимые товары (`partials/seo/cities.blade.php`). Атрибут `title` ссылки: «Купить в Тирасполе».

### Sitemap

`/sitemap.xml` строит `App\Services\SitemapBuilder`:

- общие страницы и категории;
- для каждого активного города **с хотя бы одним видимым товаром**: главная, каталог, магазины, распродажи, категории,
  магазины и товары — по адресам города;
- товары и магазины без активного города (или при выключенных региональных URL) — по общим адресам;
- у каждой записи есть `<lastmod>`;
- если записей больше `SEO_SITEMAP_CHUNK` (по умолчанию 40 000, предел Google — 50 000), `/sitemap.xml` становится
  индексом со ссылками на `/sitemap-1.xml`, `/sitemap-2.xml` …; номер за пределами — 404;
- готовый список кешируется на `SEO_SITEMAP_TTL` секунд (0 — не кешировать).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SEO_COUNTRY_CODE` | `MD` | Код страны в адресе магазина (schema.org) |
| `SEO_AREA_NAME` | `Приднестровье` | Название территории, когда город не выбран |
| `SEO_SAME_AS` | пусто | Официальные страницы бренда через запятую (Instagram, Telegram, Facebook) |
| `SEO_SITEMAP_CHUNK` | `40000` | Записей в одном файле sitemap |
| `SEO_SITEMAP_TTL` | `900` | Секунд хранить список страниц sitemap (0 — без кеша) |
| `SEO_STATS_TTL` | `600` | Секунд хранить счётчики товаров/магазинов для описаний |

`REGIONAL_SEO_ENABLED` больше не отключает canonical, robots, description и микроразметку: они выводятся всегда.
`REGIONALITY_ENABLED` и `REGIONAL_URLS_ENABLED` по-прежнему определяют, есть ли у городов собственные адреса.

## Что нужно сделать вне кода

Без этого сайт может быть технически безупречным, но не выйдет в местную выдачу.

1. **Google Search Console и Яндекс.Вебмастер.** Подтвердить сайт, отправить `https://<домен>/sitemap.xml`.
   В Яндекс.Вебмастере указать регион сайта (Тирасполь / ПМР); в Search Console проверить отчёты «Страницы»
   и «Улучшения» (Товары, Хлебные крошки).
2. **Заполнить города в админке** («Населённые пункты»): «Название в предложном падеже», `meta_title`,
   `meta_description` главной страницы города — уникальный текст для каждого города, без копий.
3. **Google Business Profile и Яндекс.Бизнес.** Для каждого магазина — карточка на карте с тем же названием, адресом
   и телефоном, что и в профиле магазина на BIMM. Именно карточки на картах дают «товары рядом».
4. **Google Merchant Center** (бесплатные товарные листинги) и товарный фид — отдельная работа, фид из каталога
   нужно выгрузить.
5. **Ссылки и упоминания.** Ссылки с местных сайтов, групп и каталогов, соцсети (`SEO_SAME_AS`), отзывы покупателей.
6. **Качество данных.** Уникальные названия и описания товаров, реальные фото (не «заглушка»), точные цены, заполненные
   адрес и телефон магазина.

После выкладки: проверить отдельные URL в «Проверке URL» Search Console и в «Проверке расширенных результатов»
Google. Рост показов обычно виден через 2–6 недель, а не сразу.
