# Ручная приёмка Filament

Дата подготовки: 08.06.2026

Проверка выполняется на `/admin` под администратором. Для тестовых данных используйте staging или локальную базу, которую можно восстановить.

## 1. Доступ

- [ ] Гость перенаправляется на `/admin/login`.
- [ ] Обычный пользователь получает 403.
- [ ] Администратор открывает `/admin`.
- [ ] Выход из панели завершает сессию.

## 2. Пользователи

- [ ] Список, поиск и фильтр по роли работают.
- [ ] Новый пользователь создаётся с валидным паролем.
- [ ] Невалидный email и пустые обязательные поля показывают ошибки.
- [ ] Роль назначается только через отдельное действие.
- [ ] Баланс меняется только через отдельное действие с обязательной причиной.
- [ ] Администратор не может удалить собственную учётную запись.

## 3. Продавцы

- [ ] Магазин создаётся только для пользователя без магазина.
- [ ] Логотип загружается и отображается.
- [ ] Название, телефон, город и ссылки сохраняются.
- [ ] Владелец и alias недоступны для изменения после создания.
- [ ] На странице редактирования видны товары магазина.
- [ ] Удаление требует подтверждения.

## 4. Товары и изображения

- [ ] Товар создаётся в конечной категории.
- [ ] Родительская категория вызывает понятную ошибку.
- [ ] Активный товар без изображения не сохраняется.
- [ ] Изображение загружается и отображается в preview.
- [ ] Можно выбрать главное изображение.
- [ ] Удаление главного изображения назначает следующее главным.
- [ ] Нельзя загрузить более пяти изображений.
- [ ] Публикация, снятие с публикации и поднятие работают.
- [ ] Ограничения активных и VIP-товаров соблюдаются.
- [ ] Цена и цена со скидкой отображаются в `RUP`.

## 5. Категории

- [ ] Список категорий открывается без ошибок.
- [ ] Дерево отображает все уровни и статусы.
- [ ] Создание корневой и дочерней категории работает.
- [ ] Нельзя назначить категорию родителем самой себе или своему потомку.
- [ ] Нельзя удалить категорию с дочерними категориями или товарами.
- [ ] После изменений категории видны на публичном сайте.

## 6. Баланс и VIP

- [ ] Администратор меняет баланс пользователя только с указанием причины; итог не уходит в минус.
- [ ] Цена дня VIP меняется на странице «Настройки VIP» и сразу действует для новых покупок.
- [ ] VIP у товара можно включить вручную (без списания с баланса), в том числе бессрочный.
- [ ] Все операции с балансом (корректировка, пополнение картой, благодарность разработчику, покупка VIP) появляются в журнале.

## 7. Журнал действий

- [ ] Журнал доступен только администратору.
- [ ] Поиск по описанию работает.
- [ ] Фильтры группы, инициатора и продавца работают.
- [ ] Модальное окно показывает properties, IP, объект и дату.
- [ ] Изменение или удаление записей из интерфейса невозможно.

## 8. Интерфейс

- [ ] Все подписи и уведомления отображаются на русском.
- [ ] Ошибки валидации видны рядом с полями.
- [ ] Таблицы и формы работают на ширине 360–390 px.
- [ ] Модальные окна не выходят за границы экрана.
- [ ] Длинные названия не ломают таблицы.
- [ ] Навигация остаётся доступной после ошибок формы.
