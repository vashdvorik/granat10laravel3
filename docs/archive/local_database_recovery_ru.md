# Архив: восстановление локальной базы данных

Дата инцидента: 07.06.2026

## Состояние

Во время проверки миграций команда `php artisan migrate:fresh --env=testing --force` использовала локальное MySQL-подключение из `.env`, потому что файл `.env.testing` отсутствовал.

База `granat2` была пересоздана миграциями. Пользовательские данные в таблицах отсутствуют.

Владелец проекта подтвердил, что это тестовая база данных. Восстановление не требуется.

## Что проверено

- SQL-дампы в каталоге проекта и каталогах OpenServer не найдены;
- MySQL binary logging выключен (`log_bin=OFF`);
- найденные ZIP-архивы содержат код и seeders, но не SQL-дампы.

## Варианты восстановления

Раздел сохранён только как журнал инцидента. Рабочие данные не потеряны.

Не запускать `migrate:fresh`, `migrate:reset` или `db:wipe` вне PHPUnit.

## Защита дальнейших проверок

Все последующие тесты выполняются через `php artisan test`, где `phpunit.xml` принудительно использует SQLite `:memory:`.

Тест application-owned миграций создаёт отдельное SQLite-подключение `authorization_schema` и не обращается к MySQL.

В корень проекта добавлен `.env.testing` с `DB_CONNECTION=sqlite` и `DB_DATABASE=:memory:`. Команды с `--env=testing` больше не используют настройки MySQL из `.env`.
