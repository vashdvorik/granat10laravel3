# Архив документации

Здесь сохранены завершённые планы, старые аудиты и первоначальные требования.

Архив нужен для понимания принятых решений, но не описывает гарантированно
актуальное поведение системы. Перед использованием любого фрагмента необходимо
сверить его с кодом, миграциями, конфигурацией и тестами.

Актуальная документация находится в родительской папке `docs`.
