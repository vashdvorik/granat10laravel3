# Архив документов

Здесь лежат завершённые планы, первоначальные требования и старые аудиты. Они сохранены как
исторический контекст и **не описывают текущую версию**: в частности, в части документов ещё
упоминаются тарифы (пакеты), Voyager и другие подсистемы, которых больше нет.

Источник истины — код, автоматические тесты и документы в корне `docs/`.
